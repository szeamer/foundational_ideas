# How to add a document to the website

## Upload the Word file
1. Open the documents page (bookmark it): **https://github.com/szeamer/foundational_ideas/tree/main/documents**
2. Click **Add file** (top right), then **Upload files**.
3. Drag in your Word file.
4. Click the green **Commit changes** button.

The website updates by itself within about four minutes. It makes a PDF of the document
automatically so people can read it in their browser, and readers can also download the Word file.

The file name becomes the title on the website. For example, `Foundational Struggles.docx`
shows up as **Foundational Struggles**.

## If the PDF on the website doesn't look right
The automatic PDF can come out slightly different from Word, for example with lines out of alignment.
If that happens, make the PDF yourself: in Word, choose **File → Save As**, pick **PDF**, keep the
same name as the Word file, and upload it the same way. The website will then use your PDF instead.

## Updating a document
Upload a new file with **exactly the same name**. It replaces the old one.

## Removing a document
On the documents page, click the file's name, then click the **⋯** menu (top right) and choose **Delete file**,
then **Commit changes**.

## If something looks wrong
Nothing is ever lost. Every earlier version is kept, so just get in touch and it can be put back.
